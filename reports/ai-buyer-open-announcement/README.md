# 구매 AI Concierge 1차 서비스 오픈 안내

사용자 제공 포스터 이미지를 바탕으로 재구성한 1080x1920 세로형 단일 HTML 안내 포스터입니다.

## 파일

- `index.html`: 브라우저에서 바로 열리는 독립 HTML 포스터
- `slides.json`: 단일 포스터 메타데이터
- `content.json`: 메시지 구조, 디자인 방향, 레퍼런스 기록

## 디자인 방향

- 9:16 포스터 캔버스에 맞춘 큰 헤드라인과 오렌지 신호색
- 구매 업무 흐름을 보여주는 모듈형 서비스 카드
- 1차 오픈 이후의 확장을 한 줄 타임라인으로 표현
- 화면에는 출처, 제작 메타, 레퍼런스 표기 미노출
