# AI 에이전트 품질 가이드 실무 교육자료

이 폴더는 `ai_agent_quality Guide.docx` 기반 실무 교육 HTML 덱을 만들기 위한 작업 폴더다.

현재 완료된 작업:

- Refero 공개 Styles에서 교육자료에 의미 있는 예시 6종 선정
- `refero-reference-lock.json`에 출처, 이미지 URL, 적용 장표, 금지 원칙 기록
- `refero-reference-board.html`에 참조 보드 구성

적용할 Refero 방향:

- `Slite`: 지식/교육형 카드와 warm editorial tone
- `Tailscale`: 실무 체크리스트와 기술 워크시트
- `Seline Analytics`: 품질 지표와 루브릭 scorecard
- `Linear`: 프롬프트와 실행 구조 진단 command panel
- `Resend`: 로그, 이벤트, 검증 실패 사례 panel
- `Relate`: 한국어 본문과 현업 적용 패널

다음 작업:

1. `ai_agent_quality Guide.docx` 내용을 추출한다.
2. 실무사용자 교육 목차를 10장 이상으로 재구성한다.
3. Refero reference lock을 적용해 `index.html`, `slides.json`, `content.json`을 생성한다.
4. 1920x1080 overflow와 한국어 줄바꿈을 검증한다.
