# Korean Report Logic Craft

## Use decision-first structure

A Korean executive report should make the requested decision visible early.

Recommended order:

1. 판단 또는 요청
2. 이유
3. 선택지
4. 리스크
5. 실행안

## Separate fact and interpretation

Do not mix raw facts and recommendation in the same visual block.

| Block | Content |
|---|---|
| Fact | 수치, 일정, 현황 |
| Interpretation | 의미, 영향, 병목 |
| Ask | 승인, 선택, 보류, 추가검토 |

## Make tradeoffs explicit

Executives rarely need every detail. They need the tradeoff.

Use:

- 비용 vs 속도
- 안정성 vs 유연성
- 단기효과 vs 장기확장성
- 내재화 vs 외부도입
