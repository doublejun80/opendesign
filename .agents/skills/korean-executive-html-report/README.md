# Korean Executive HTML Report Skill

This skill generates Korean executive report decks as editable 16:9 HTML panels.

Use it when a user asks for:

- 임원보고
- 보고자료
- 전략보고
- 검토보고
- 비교분석 장표
- 의사결정 자료
- PPT 대체 HTML 인포그래픽 패널

Recommended command in Codex:

```text
Use the korean-executive-html-report skill and korean-executive-report design system. Create a 6-slide Korean executive report deck as 1920x1080 HTML.
```
