# 한국어 보고자료 문법

## 장표 제목

좋은 제목은 명사형 주제가 아니라 판단 문장이다.

| 약한 제목 | 좋은 제목 |
|---|---|
| 시장 현황 | 수요는 늘었지만 구매 전환은 특정 채널에 집중됨 |
| 주요 이슈 | 비용보다 운영 리스크가 먼저 터질 가능성이 큼 |
| 추진 방향 | 3개월 PoC로 성과 기준을 먼저 검증해야 함 |

## 기본 장표 패턴

1. 상단: 1줄 결론
2. 중단: 근거 2~3개
3. 하단: 판단/요청/다음 액션

## 한국식 임원보고에 맞는 표현

- “필요합니다”보다 “필요”처럼 짧게 쓴다.
- “검토가 요구됩니다”보다 “검토 필요”처럼 쓴다.
- 수치가 있으면 문장보다 수치를 먼저 배치한다.
- ‘왜 지금 봐야 하는지’를 1장 안에 넣는다.

## 피해야 할 표현

- 혁신적인 솔루션
- 압도적인 효율성
- 데이터 기반 고도화
- 새로운 패러다임
- 미래 경쟁력 확보

이런 표현은 구체적 결과, 수치, 운영 변화로 바꾼다.
