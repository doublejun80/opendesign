# 한국어 보고자료 문법

## 장표 제목

좋은 제목은 긴 문장이 아니라 판단이 보이는 키워드형 메시지다.
특별히 문장형을 요구받지 않았다면 `한다`, `이다`, `필요하다`로 끝내지 않는다.

| 약한 제목 | 좋은 제목 |
|---|---|
| 시장 현황 | 수요 증가 / 구매 전환 특정 채널 집중 |
| 주요 이슈 | 비용 이슈보다 운영 리스크 우선 |
| 추진 방향 | 3개월 PoC / 성과 기준 선검증 |

## 기본 장표 패턴

1. 상단: 1줄 결론
2. 중단: 근거 2~3개
3. 하단: 판단/요청/다음 액션

## 한국식 임원보고에 맞는 표현

- “필요합니다”보다 “필요”처럼 짧게 쓴다.
- “검토가 요구됩니다”보다 “검토 필요”처럼 쓴다.
- “관리해야 한다”보다 “관리 포인트”처럼 쓴다.
- “근거를 남긴다”보다 “근거 이력화”처럼 쓴다.
- “우선이다”보다 “우선 적용”처럼 쓴다.
- 수치가 있으면 문장보다 수치를 먼저 배치한다.
- ‘왜 지금 봐야 하는지’를 1장 안에 넣는다.

## 피해야 할 표현

- 혁신적인 솔루션
- 압도적인 효율성
- 데이터 기반 고도화
- 새로운 패러다임
- 미래 경쟁력 확보

이런 표현은 구체적 결과, 수치, 운영 변화로 바꾼다.
