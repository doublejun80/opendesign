# Reference Source Usage

## Refero / Explicit Reference Sources

These tools are reference suppliers, not the final report renderer.

When the user selects one Refero sample as the desired mood, treat it as a
deck-level master reference, not a loose inspiration source.

For a Refero master reference, preserve:

- layout structure
- information density
- typography rhythm
- line/surface/spacing feel
- color restraint
- image, diagram, and shape treatment
- polished sample atmosphere
- memorable visual devices

Do not reduce this to “structure only.” The sample's taste is the point.
Deck consistency should come from a separate brand/report layer:

- SK AX logo position
- common metadata
- common color limits
- Korean typography rules
- shared line weight and document-number system
- common footer/source area

Slide layouts must follow the user's scenario. Do not pre-map slide numbers to fixed
template genres unless the scenario itself requires it.

For ordinary references explicitly named by the user, use them to collect:

- card density
- flow structure
- comparison layout
- information hierarchy
- modal/decision patterns
- SaaS-style clean visual language

## Open Design Templates

Useful inspiration categories:

- Open-Slide 1920 canvas deck
- Html Ppt Taste Editorial
- Html Ppt Weekly Report
- Bento Insight Grid
- Graphify / Swiss / Editorial templates

## Rule

Never let a reference source dictate the report logic.  
The report logic must follow Korean executive reporting grammar.
When a Refero master is specified, let it dictate the visual language strongly, while
the scenario dictates the slide logic.
