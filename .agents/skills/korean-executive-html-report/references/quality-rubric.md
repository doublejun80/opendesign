# Quality Rubric

Score each deck from 1 to 5.

| 항목 | 1점 | 5점 |
|---|---|---|
| 메시지 선명도 | 주제가 보이지 않음 | 장표마다 판단이 보임 |
| 한국어 보고 문체 | `한다/이다/필요하다` 문장형 남발 | 핵심 키워드·명사형·상태 라벨 중심 |
| 한국어 자연스러움 | 번역투/기계적 명사 나열 | 실제 임원보고처럼 짧고 자연스럽게 읽힘 |
| 정보 구조 | 글상자 나열 | 비교/흐름/리스크 구조가 보임 |
| 시각 방향 선택 | 색상·폰트·장르를 임의 적용하거나 사용자에게 떠넘김 | Refero 마스터가 없으면 후보를 내부 비교하고, 마스터가 있으면 적용 전략만 비교 |
| Refero 마스터 적용 | 구조만 흉내 내거나 장표별 고정 템플릿으로 변질 | 미감·밀도·선/면/여백·타이포 리듬을 보존하고 시나리오별 레이아웃 설계 |
| 시각 완성도 | PPT 기본 도형 느낌 | HTML 인포그래픽 느낌 |
| 수정 가능성 | 이미지 한 장 | JSON/HTML/CSS로 분리 |
| 출력 안정성 | 잘림/깨짐 | 1920×1080 안정 |

4점 미만이면 다시 수정한다.
