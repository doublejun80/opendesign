# Layout Patterns for Korean Report Decks

## 1. Executive Summary

```text
[Top-line conclusion]
[Large decision badge] [3 evidence cards]
[Bottom ask / next step]
```

## 2. As-Is / To-Be

```text
[Conclusion]
[As-Is column] → [Transition logic] → [To-Be column]
[Operational implication]
```

## 3. Option Matrix

```text
Rows: cost / speed / risk / scalability / recommendation
Columns: Option A / Option B / Option C
Use one emphasized recommended column.
```

## 4. Risk-Control Grid

```text
Risk level / trigger / impact / control / owner
```

## 5. Roadmap

```text
Phase 1: Validate
Phase 2: Pilot
Phase 3: Scale
Phase 4: Govern
```

## 6. Bento Insight

Use unequal cards only when hierarchy is meaningful. Do not make every card the same size if one card is the core conclusion.
