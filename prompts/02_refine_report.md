# 보고자료 수정 프롬프트

```text
현재 reports/<slug>/index.html을 수정해줘.

수정 요청:
- ...

수정 원칙:
1. 장식보다 메시지 구조를 먼저 고쳐줘.
2. 한국어 문장을 더 자연스럽게 다듬어줘.
3. 1920×1080에서 잘리지 않게 유지해줘.
4. 변경한 파일과 변경 이유를 설명해줘.
5. 필요하면 slides.json도 함께 업데이트해줘.
```

자주 쓰는 수정 요청 예시:

```text
2장을 더 임원보고 느낌으로 바꿔줘. 표를 줄이고 핵심 판단 3개 카드로 바꿔줘.
```

```text
전체 톤이 스타트업 피치덱 같아. 한국 대기업 임원보고 느낌으로 더 절제해줘.
```

```text
4장 대안 비교표가 너무 촘촘해. 추천안이 한눈에 보이게 우측 컬럼을 강조해줘.
```
