# Lazyweb/Mobbin/Refero 레퍼런스 선택 사용 프롬프트

```text
Lazyweb/Mobbin/Refero 같은 레퍼런스 MCP가 연결되어 있다면, 아래 주제에 맞는 자료와 화면 패턴을 찾아 참고해줘.

주제:
...

찾을 패턴:
- Lazyweb: 업무 맥락, 사례, 의사결정 기준, 근거 수치 후보
- Mobbin: 도형, 이미지 배치, 카드 구조, 상태 라벨, 비교 화면 패턴
- 비교 구조
- 승인/의사결정 흐름
- 요약 카드 구조
- 타임라인/로드맵 구조
- 리스크/상태 표시 방식

주의:
레퍼런스 화면을 그대로 복제하지 말고, 정보 밀도와 배치 원칙만 추출해줘.
최종 결과물은 한국어 임원보고용 16:9 HTML 덱이어야 한다.
대시보드처럼 만들지 말고, 보고자료 문법으로 재구성해줘.
도형과 이미지는 장식이 아니라 판단 흐름, 리스크, 상태, 비교 기준을 설명할 때만 사용해줘.
반영한 레퍼런스는 content.json의 references 배열에 source/title/takeaways로 남겨줘.
```
