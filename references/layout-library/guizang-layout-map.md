# Guizang Layout Map

이 문서는 Guizang PPT Skill의 시각 스타일을 복제하기 위한 문서가 아니다.
한국어 임원보고에서 장표 구조를 고를 때 참고하는 레이아웃 라이브러리다.

## 사용 원칙

- Guizang은 레이아웃 이름과 배치 구조만 참고한다.
- 색상, 폰트, 여백, 카드 스타일은 한국어 보고서 디자인 시스템을 따른다.
- 장표 번호별 고정 배정은 금지한다.
- 보고 논리와 한국어 가독성이 레이아웃보다 우선한다.

## 레이아웃 목록

| 레이아웃 | 용도 | 한국어 보고자료 적용 |
|---|---|---|
| Statement | 한 장에 핵심 판단 1개를 크게 제시 | 1장 결론, 의사결정 요청 |
| Duo Compare | A/B 비교 | As-Is / To-Be, 기존안 / 개선안 |
| KPI Tower | 3~5개 핵심 숫자 강조 | 기대효과, 비용절감, 일정, 리스크 수치 |
| Loop Diagram | 반복 구조, 운영 사이클 | 검토 → 실행 → 모니터링 → 개선 |
| Image Hero | 큰 이미지와 짧은 메시지 | 서비스 컨셉, 화면 예시, 방향성 제시 |
| Closing Manifesto | 마지막 메시지와 실행 요청 | 결재 요청, 다음 액션, 원칙 선언 |

## 선택 기준

- 결론 하나가 가장 중요하면 `Statement`
- 양쪽 관점 차이가 핵심이면 `Duo Compare`
- 숫자 3~5개가 판단 근거이면 `KPI Tower`
- 운영 반복 구조를 보여야 하면 `Loop Diagram`
- 화면, 제품, 서비스 컨셉을 보여야 하면 `Image Hero`
- 마지막 승인 요청이나 실행 선언이면 `Closing Manifesto`

## 한국어 보고서 변환

Guizang 레이아웃을 적용할 때는 다음 항목을 반드시 한국어 보고서 방식으로 바꾼다.

- 문장형 설명 → 핵심 키워드와 판단 라벨
- 장식적 배경 → 정보 구조를 돕는 선과 면
- 원본 색상 → SK AX 또는 한국어 보고서 팔레트
- 작은 본문 → 1920x1080에서 읽히는 크기
- 이미지 중심 구성 → HTML 텍스트와 도식 중심 구성
