# Modu-Style Korean Business QA Archetype Map

Purpose: use `modu-ai/cowork-plugins` as an operating-quality reference for Korean B2B
documents: Korean tone, domain fit, quality gates, and handoff readiness.

## Useful Archetypes

| Need | Archetype | Apply in this workspace |
|---|---|---|
| Korean naturalness | humanize-korean / ai-slop reviewer idea | Remove AI-ish repetition, awkward endings, and translation tone |
| HTML report | html-report / html-slide idea | Keep single-file local HTML, exportable 16:9 panels |
| Weekly or project report | weekly-report idea | Separate result, issue, next action, risk, owner |
| Executive summary | executive-summary idea | What / so what / now what, but rewritten as Korean report fragments |
| Proposal / handoff | proposal-writer idea | Clarify scope, assumptions, deliverables, owner, due date |

## How To Use

- Treat this as a QA and operating-language reference, not a design template.
- Keep Korean B2B conventions: concise labels, clear owner, concrete action, source
  separation, and no decorative copy.
- Apply the QA gate to every slide before export.
