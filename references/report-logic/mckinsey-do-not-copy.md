# McKinsey Reference Guardrails

Use McKinsey-style references for report logic only.

## Do

- Use the idea of a template catalog to decide slide roles.
- Convert source notes into summary, issue tree, option matrix, roadmap, KPI, risk, or
  handoff slides.
- Keep conclusions and evidence visually separated.
- Use Korean report copy, not English-consulting phrasing translated word for word.

## Do Not

- Do not copy external template colors, fonts, spacing, examples, or commercial branding.
- Do not force every deck into a consulting-pitch style.
- Do not use tiny text, dense footnotes, or over-compressed titles that break Korean.
- Do not expose `McKinsey style` as visible slide copy unless the user asks for a study
  or comparison document.

## Project Rule

For this workspace, the McKinsey reference is a role router. The final visual system is
the Korean executive/business HTML report system plus any user-selected master reference.
